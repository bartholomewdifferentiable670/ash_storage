## 🚀 Getting started

Open the application by double-clicking the icon. You will see a clean dashboard. To add your first file, click the button labeled "Add Attachment." You can select any file from your computer. The software then creates a copy and stores it in the central database. You can label each file with a name or a tag. This makes it easy to find them later.

## 🔍 Managing your files

Use the search bar at the top of the window to find items. Type a keyword or a date. The software shows matching files instantly. Right-click any file to rename it or move it to a specific category. You can also view details like file size and the date of upload.

## 🛡️ Security and backups

The application stores your data in a secure folder on your machine. You control these files at all times. If you want to move your storage location, go to Settings and change the file path. Regular backups prevent data loss. You should copy the storage folder to an external drive or cloud service once a week.

## 🔧 Troubleshooting

If the software does not open, restart your computer. Sometimes a system process might block the application. Check that you have the latest drivers for your graphics card. If you see an error message, write down the code or take a screenshot. This helps if you need to ask for help elsewhere. Most issues stem from incomplete installations. If you suspect an issue, uninstall the software and run the installer again.

## ⚙️ Common settings

The settings menu offers choices for your workflow. You can set a default view for your documents. Choose between list view or thumbnail view. You can also change the theme from light mode to dark mode. These changes take effect immediately.

## 📂 Handling large files

The software handles files of many sizes. If you work with very large documents, you might notice a slight delay during the upload process. The progress bar at the bottom tells you when the task finishes. Do not close the app while the bar moves.

## 📄 Organization tips

Group your files using folders. Create a folder for work, another for personal documents, and one for receipts. Click "New Folder" in the main menu to create a structure that fits your habits. This keeps your interface clear.
